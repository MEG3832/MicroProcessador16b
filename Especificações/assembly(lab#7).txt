Programa de Teste - Memória RAM (Lab #7)
=========================================================

# Inicialização de Ponteiros
LD R1, 10       # R1 = Endereço 10 (0x0A)
LD R3, 50       # R3 = Endereço 50 (0x32)
LD R5, 120      # R5 = Endereço 120 (0x78)

# Inicialização de dados e Sequência de Escritas Espaçadas (SW)
LD A1, 165      # A1 = Dado A (0x0A5)
SW A1, R1       # RAM[10]  = 165 (0x0A5)
LD A2, 500      # A2 = Dado B (0x1F4)
SW A2, R3       # RAM[50]  = 500 (0x1F4)
LD A1, 571      # A1 = Dado C (0x23B)
SW A1, R5       # RAM[120] = 571 (0x23B)

# 3. Limpeza dos Registradores de Dados (Para garantir que a leitura vem da RAM)
LD R2, 0        # Limpa R2
LD R4, 0        # Limpa R4
LD R6, 0        # Limpa R6

# 4. Leitura em Ordem Diferente da Escrita (LW)
LW R6, R1       # R6 recebe RAM[10] (Esperado: 165)
LW R2, R5       # R2 recebe RAM[120] (Esperado: 571)
LW R4, R3       # R4 recebe RAM[50] (Esperado: 500)
